# Grok Library Downloader

`https://grok.com/library`의 이미지와 비디오를 무한 스크롤 끝까지 탐색한 뒤 다운로드하거나 오래된 순서로 삭제하는 Chrome 확장 프로그램이다.

## 설치

1. Chrome에서 `chrome://extensions`를 연다.
2. 우측 상단의 **개발자 모드**를 켠다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누른다.
4. 이 프로젝트 폴더(`grok_downloader`)를 선택한다.

## 사용

1. Grok에 로그인하고 `https://grok.com/library`를 연다.
2. 페이지를 한 번 새로고침한다. 설치 전에 열려 있던 탭에는 콘텐츠 스크립트가 없을 수 있다.
3. 확장 프로그램 아이콘을 누르고 이미지/비디오를 선택한다.
4. 필요한 경우 최대 스크롤 횟수를 입력한다. 비워두면 끝까지 탐색한다.
5. **다운로드 시작**을 누른다.
6. 탐색 중에는 해당 탭을 닫지 않는다. 팝업은 닫아도 작업이 계속된다.

파일은 기본 다운로드 폴더의 `Grok Library_YYMMDD_hhmmss`(작업 시작 시각) 하위에 저장된다. Chrome 설정에 따라 여러 파일 자동 다운로드 허용 여부를 묻는 안내가 나타날 수 있다.

## 삭제

1. 확장 프로그램 업데이트 후 `chrome://extensions`에서 확장 프로그램을 새로고침하고 Grok 라이브러리 탭도 새로고침한다.
2. 라이브러리를 최신순으로 표시하고 삭제할 이미지/비디오 유형을 선택한다. 검색이나 사이트 필터가 적용된 경우 해당 목록만 대상이 된다.
3. **삭제할 미디어 개수**에 양의 정수를 입력한다. 비워두면 선택한 유형 전체가 대상이 된다. 다운로드의 최대 스크롤 횟수와는 별개다.
4. **오래된 순서로 삭제**를 누른다. 목록을 처음부터 끝까지 탐색하여 항목 ID와 순서를 수집한다.
5. 개수를 지정한 부분 삭제는 탐색 완료 후 별도 확인 없이 바로 실행한다. 개수 미입력 또는 입력한 개수가 대상 수 이상인 전체 삭제는 확장 팝업을 다시 열어 **영구 삭제 실행**을 눌러야 진행된다. 전체 삭제 확인에서 **취소**를 누르거나 승인하지 않으면 삭제하지 않는다.
6. 목록 맨 아래의 마지막 미디어부터 역순으로 삭제한다. 이미지와 비디오를 모두 선택하면 각각 한 항목으로 계산한다.

삭제는 되돌릴 수 없으므로 필요한 파일을 먼저 다운로드해야 한다. 삭제에는 다운로드의 `.png`, `.svg`, `.webp` URL 제외 규칙을 적용하지 않는다. 작업 중에는 스크롤, 검색, 정렬, 필터 변경, 항목 추가 및 수동 삭제를 하지 않는다.

팝업을 다시 열면 삭제 진행 상태를 확인하거나 **중지**할 수 있다. 중지 전에 사이트로 전달된 삭제는 취소할 수 없으며, 처리 중이던 항목은 페이지에서 직접 확인해야 한다. 다운로드와 삭제는 같은 탭에서 동시에 실행하지 않는다.

삭제 완료, 오류 중단, 사용자 중지, 확인 취소 시 Grok 페이지 오른쪽 아래에 결과 토스트를 한 번 표시한다. 토스트는 12초 후 자동으로 사라지며 **닫기**로 직접 닫을 수도 있다. 전체 삭제와 테스트 모드의 탐색이 끝나 확인이 필요하면 확인 내용을 담은 대기 토스트를 자동으로 사라지지 않게 표시하며, 팝업에서 실행 또는 취소를 선택하거나 중지하면 제거된다. 상세 결과는 확장 팝업에도 유지된다. 업데이트 전에 이미 진행 중이던 작업에는 적용되지 않으므로 해당 작업이 끝난 뒤 확장 프로그램과 페이지를 새로고침한다.

### 현재 위치에서 이어서 삭제

**현재 위치에서 삭제 (전체 탐색 생략)**을 선택하고 개수를 입력한 뒤 **현재 위치에서 즉시 삭제**를 누른다. 맨 위로 돌아가거나 목록 전체를 다시 탐색하지 않고, 현재 로드된 미디어 중 선택한 유형을 아래쪽부터 지정 개수만큼 즉시 삭제한다. 팝업은 자동으로 닫히지 않으므로 완료 후 같은 개수로 반복 실행할 수 있다.

이 옵션은 개수 입력이 필수이며 테스트 모드와 동시에 선택할 수 없다. 현재 읽힌 대상보다 많은 개수를 입력하면 일부를 먼저 삭제하지 않고 중단한다. 전체 목록의 가장 오래된 미디어를 지우려면 목록 끝에서 실행해야 한다. 행 삭제 후 사이트의 화면 재배치와 결과 검증을 위한 목록 끝 위치 보정은 발생할 수 있다. 삭제 중에는 직접 스크롤하거나 목록을 변경하지 않는다.

### 스크롤 없는 테스트 삭제

1. 테스트용 미디어를 추가하고 해당 미디어가 목록 앞쪽에 로드되도록 직접 이동한다. 스크롤 위치나 첫 미디어 행 번호가 정확히 0일 필요는 없다.
2. 이미지 테스트 시 이미지 유형만 선택하고 **테스트: 앞에서부터 삭제 (스크롤 없음)**을 체크한다.
3. 삭제 개수를 입력하고 **앞에서부터 테스트 삭제**를 누른다. 개수 입력은 필수이며 전체 삭제는 지원하지 않는다.
4. 같은 팝업에 나타나는 대상 파일명을 확인한 후 **영구 삭제 실행**을 누른다. 테스트 모드도 실제 미디어를 영구 삭제한다.

현재 렌더링된 대상 ID와 시작 스크롤 위치를 고정하여 읽힌 목록 앞쪽부터 삭제하며 자동 스크롤하지 않는다. 전체 목록의 첫 항목이 아니라 현재 로드된 항목 기준이므로 확인 화면에서 대상 파일명을 반드시 확인한다. 현재 읽을 수 있는 항목보다 큰 개수, 확인 대기 또는 삭제 중 사용자 스크롤, 도중에 화면에서 사라진 대상은 오류로 중단한다. 삭제로 앞쪽 행 번호가 변경되더라도 고정한 ID만 처리한다. 팝업은 자동으로 닫지 않으며, 탭 전환으로 닫힌 경우 다시 열어 확인 대기 내용과 진행 상태를 확인한다. 브라우저의 네이티브 확인창은 사용하지 않는다. 체크를 해제하면 기존 오래된 순서 삭제로 돌아간다.

### 삭제 지원 범위

- 제공된 `data-library-item-id` 항목과 `data-index` 가상 목록 구조를 기준으로 동작함
- 아래쪽이 오래된 순서라는 전제가 필요하며 날짜 문자열을 별도로 정렬하지 않음
- 항목에 연결된 작업 메뉴와 한국어/영어 삭제 항목을 사용하며 비공개 삭제 API를 추정하여 호출하지 않음
- 일반 개수 지정 삭제와 현재 위치 삭제는 별도 확인 없이 실행함. 전체 삭제와 테스트 모드는 실행 전 확인을 받음
- 끝 위치와 표시 항목이 약 5.4초 이상 안정적인 경우 목록 끝으로 판단함. 더 늦게 로드되는 항목까지 탐색했음을 보장하지 않음
- 개수 지정 삭제는 오래된 후보 구간의 행 누락을 검사함. 후보보다 앞쪽의 누락은 해당 삭제를 차단하지 않음. 전체 삭제 또는 입력 개수가 수집 개수 이상인 경우 전체 수집 구간을 검사함. 목록에 표시된 `data-index` 행은 미디어 버튼이 없는 구분 행이어도 읽은 행으로 인정함
- 검사 구간에 누락 행이 있으면 스크롤 간격을 화면 높이의 70%에서 35%로 줄여 전체 목록을 한 번 재탐색함. 이전 결과와 섞지 않고 새 목록으로 개수와 순서를 다시 검사하며 전체 삭제 확인은 탐색 완료 후 수행함. 재탐색 후에도 누락되면 삭제 전에 중단함. 현재 위치 삭제와 테스트 모드에는 전체 재탐색을 적용하지 않음
- 검사 구간의 행 누락, 대상 순서 변경, 메뉴 인식 실패, 삭제 결과 확인 실패 시 추가 삭제를 중단함
- 완료 수는 화면에서 항목이 사라지고 잠시 후 다시 나타나지 않는지 확인한 수이며 서버 저장 결과를 직접 검증한 수는 아님
- 사용자가 제공한 Grok 작업 메뉴의 `영구 삭제` 구조를 지원함. 실제 계정 실행과 사이트 자체 삭제 확인창의 호환성은 미검증 상태이며 지원하지 않는 구조에서는 중단함

## 테스트

삭제 메뉴 선택부터 사이트 확인창 처리와 첫 결과 확인까지 시도당 최대 약 30초간 대기하며, 5초 간격으로 대기 상태를 표시한다. 첫 대기 시간 초과 시 같은 대상 ID와 행, 스크롤 위치와 높이가 유지되고 메뉴와 확인창이 닫혀 있는 경우에만 자동 재시도 1회를 수행한다. 재시도 중에도 대상과 위치를 다시 검사하며, 재시도까지 미반영이면 다음 항목을 삭제하지 않고 중단한다. 재시도 횟수는 진행 메시지와 실패 진단에 표시하며 성공한 대상만 한 번 집계한다. 중지하거나 제한시간을 넘겨도 이미 보낸 요청은 나중에 반영될 수 있으므로 수동 재실행 전 해당 항목을 확인한다.

Node.js 18 이상에서 `npm ci` 후 `npm test`로 가상 목록, 삭제 확인/취소/중지, 개수 제한, 다열 그리드, 팝업 연결 및 다운로드 메시지 회귀 테스트를 실행한다. 테스트는 로컬 DOM에서 수행하며 실제 Grok 계정의 미디어를 삭제하지 않는다. 개발 의존성은 테스트 전용이며 확장 프로그램 설치에는 필요하지 않다.

## 현재 범위

- 현재 화면에 렌더링되는 미디어와 브라우저가 로드한 미디어 URL을 단계별로 누적함
- 이미지와 비디오 유형 선택 가능
- 최대 스크롤 횟수 제한 가능. 최초 화면 수집은 스크롤 횟수에 포함하지 않음
- 중복 URL은 한 번만 다운로드함
- `.png`, `.svg`, `.webp` 파일은 다운로드에서 제외함
- 원본 파일명 뒤에 Unix 밀리초 타임스탬프를 붙여 저장함
- 이미 받은 파일 제외와 날짜 필터는 아직 구현하지 않음

Grok 페이지 구조나 미디어 제공 방식이 변경되면 수집 규칙을 조정해야 할 수 있다.
